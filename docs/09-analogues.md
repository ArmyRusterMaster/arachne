# 9. Обзор аналогов и заимствуемые практики

## 9.1. Три технологических лидера рынка

В индустрии скрытного краулинга сформировались три основных лидера, у которых стоит заимствовать идеи:

### Camoufox (C++ / Python)
Кастомный хард-форк браузера Firefox. Главная фишка — **C++-level interception**: не внедряют JS-скрипты маскировки (которые легко детектируются антиботами), а патчат сам исходный код C++ на уровне браузерного движка. Если скрипт сайта запрашивает `navigator.webdriver` или аудио-контекст, движок на уровне C++ подставляет ложные данные.

### BrowserOxide (Pure Rust)
Самый близкий к задумке аналог, написанный с нуля на Rust — полноценный **HTML/CSS/DOM/JS движок без Chromium и CDP**. Напрямую контролирует каждую поверхность (от TLS-рукопожатия через BoringSSL до Canvas и WebGL). **Фингерпринт нативный, а не инжектируемый**. По результатам тестов успешно обходит защиты на **118 из 126** самых защищённых сайтов в мире (включая жёсткие корпоративные WAF). Идеален для изучения структуры виртуального DOM и связки с JS-рантаймом.

### Spider (`spider-rs`) (Rust)
Эталон производительности и масштабирования распределённых краулеров. **Concurrency-first** (параллелизм): умеет на лету стримить данные, превращая их в Markdown/JSON для AI-агентов. Стоит подсмотреть архитектуру **распределения задач по нодам**.

## 9.2. Дополнительные open-source находки для изучения

### Имитация сетевого уровня (TLS/H2)
`reqwest-impersonate` и `wreq` — хард-форки библиотеки `reqwest`. Лучшие примеры того, как пропатчить BoringSSL, чтобы контролировать JA3/JA4-отпечатки, TLS-расширения и HTTP/2-параметры (SETTINGS-фреймы) и эмулировать Chrome или Safari вплоть до байта.

### Pure-Rust headless-движки (референс, а не зависимость)

> **Важно:** эти движки мы **не внедряем** в проект. Они — источники практик/идей, решением запускается **собственный модульный движок** ([11-browser-engines.md](11-browser-engines.md#114-что-берём-из-чужих-движков-а-не-их-код)).

- **`browser_oxide` (BrowserOxide)** — главный архитектурный аналог (см. выше).
- **`obscura` (Obscura)** — ориентирован на AI-агентов, мощный автономный лёгкий headless-браузер на Rust (~30 МБ RAM). Из коробки реализует `--stealth` режим: блокировка трекеров, рекламы и телеметрии, маскировка рантайма. Полезно посмотреть логику изоляции страниц.
- **`recluse`** — фреймворк для краулинга на Rust, вдохновлённый Python-библиотекой Scrapy. Отсюда можно позаимствовать паттерны построения очередей задач (Work Queues), конвейеров обработки данных (Pipelines) и строго типизированных асинхронных воркеров.
